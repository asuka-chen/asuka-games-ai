# 星渊 V0.15.0 安卓激励广告安装候选

下载 Star-Abyss-Android-v0.15.0-ads.apk，在 Android 9+ ARM 手机上覆盖安装。与本项目 V0.14.0 使用相同签名，versionCode 1500。不要先卸载旧版，以免删除本机存档。

机库或星图打开“广告与隐私设置”，自愿启用后等待视频准备就绪。星图每层可选领取 120 星币；失利后每局可选一次半血复活，保留当前战斗进度。拒绝与停用不影响普通游戏。未接入开屏。

真实 TapADN 5.3.0.4 SDK 调试编译与 R8 发布编译通过，213 项规则、8 组 Java 状态、5 组游戏广告桥接和 11 组手机浏览器场景通过。广告桥接测试使用替身，不是真实广告。当前云端没有 Android 真机或 ARM 模拟器，尚需用设备验证真实视频、无填充、奖励到账和覆盖更新；此候选不等同于上架验收通过。
