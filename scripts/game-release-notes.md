星渊：无限火力 — Windows x64 可玩原型 0.1

下载 `Star-Abyss-Windows-x64.zip`，解压完整文件夹，双击 `Star-Abyss.exe`。无需安装 Node.js、Python 或联网游玩。

包含三章分支星图、五种武器、弹幕战斗、遗物构筑、节点服务与章节 Boss。素材来自 Kenney CC0 资源，许可随游戏附带。

17 项核心规则与稳定性测试、浏览器功能检查和 Linux Electron 离线启动检查已通过。Windows 实机尚未验证，部分复杂遗物和进化效果采用首版简化实现。具体范围见游戏包中的 DEVELOPMENT.md。

`Star-Abyss-Source-v0.1.0.zip` 是与游戏包对应的源码快照，包含开发说明与测试。请以该源码附件为准；本草稿不修改仓库主分支。
