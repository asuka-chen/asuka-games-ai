# 星渊：无限火力 — 可玩原型 0.12.0

这是根据用户提供的 V1.4 策划制作的首个可运行 PC 版本，不是完成了全部策划验收的正式商业发行版。

0.6.0 加入机体残影/回响分身、满成长补给和舰载经济服务，并修复射线进化门槛；0.5.0 的 Boss 持续压力、开场和舰船/特效/卡面保留，并保留 0.1.1 的自动射击过关修复，详见 CHANGELOG.md。版本更新保持原有存档格式与桌面应用数据位置。

## 已实现的工作流

- Windows x64 桌面打包，Electron 沙箱渲染；相同 HTML/Canvas 游戏可在浏览器运行。
- 3 种机体、5 种主武器：机炮、霰弹、轨道炮、蜂群、蓄力贯穿射线。
- v1.4 的 3 章 × 12 层星图，2—4 个分支、合法连线、两层可视范围、首领前补给、章节递进与无尽循环。没有套用旧版每 5/10 波固定精英/Boss/商店时间表。
- 六种普通敌舰角色、精英、三阶段首领；血量跨阶段连续结算，没有锁血恢复。
- 实时移动、鼠标驾驶、基础手柄输入、自动/手动射击、0.65 秒无敌闪避、护盾再生。
- 经验升级三选一、有限刷新；普通升级与遗物池分离。元素选择按 10 级、第三个 Boss、30 级进入队列，至多三元素；实现六组既定元素反应，其余组合只共存。
- 48 件原始遗物数据、五档品质、前置资格、叠层与主形态互斥、来源过滤、动态权重、差一件配方引导、候选无放回抽样。禁忌拾取有二次确认。
- 24 组基础共鸣判定、16 项终极进化的配方与门槛、核心保留/兑换、每局最多两次进化。
- 商店购买与三次递增费用刷新、定向重铸券、维修二选一、叠层锻造、风险事件、45 秒裂隙。
- 节点完成检查点、机库记录、遗物发现、构筑查看、伤害来源结算、JSON 日志导出。
- 游戏运行无需联网，素材许可见 CREDITS.md。

## 0.2.0 新增路线

B17—B24、U09—U16 是针对玩家反馈新增的内容，不属于原文的 16+8 配方。四种弹丸武器各有两条专属主形态进化，复用现有 48 件遗物。首个首领增加核心，新路线门槛为击败一个首领；旧路线门槛不变。同武器主形态互斥，仍可与通用辅助进化组合，每局总上限仍为两项。

机炮三连点射与逐目标弹射、霰弹九路覆盖与范围爆破、轨道炮三轨贯穿与引力场、蜂群分散锁定与母弹分裂均有独立攻击机制。衍生伤害保留一层限制及每秒事件预算。永恒回响继承发射数量和弹道，不再次触发进化爆破、引力或分裂。新数值仍是原型参数，尚未通过真人平衡验收。

## 0.3.0 交互、视觉与数值调整

遗物卡翻面与领取/购买/锻造为独立按钮，支持鼠标和键盘。战斗中查看持有遗物使用暂停模态。新星图第一层保留战斗并保证一个事件/商店/维修选项；已有存档中的地图不重新生成。

六元素和六反应由 `element-visuals.js` 绘制，状态/命中/射线颜色可区分。视觉事件独立于产生伤害的效果队列，上限 96，不调用游戏 RNG；因此视觉队列拥挤不会丢弃引力场，也不改变后续遗物抽样。敌弹仍在最上层绘制。

条件增伤相加、最多 +200%；弹丸总攻速至少保留 50% 原间隔，暴击率/倍率上限为 40%/2.6，射线蓄力下限 0.6 秒。每目标元素附着间隔 0.18 秒。单发引力弹的多场共享目标六跳计数；进化雷霆机神按已持有僚机层数计算基础弹伤。射线回响不会重放进化终结效果，射线全部同源伤害共用 Boss 预算。不同攻击、不同目标的预算独立；没有锁血或阻止首领死亡。

`npm run report:balance -- /path/to/previous/core.js` 可输出固定耐久目标的伤害对照到 `test-results/balance-report.json`。这是固定位置、叠加后期遗物、关闭暴击随机的合成场景，不能代表玩家通关时长。完整数值仍需结合真人反馈继续调整。

## 0.4.0 共鸣/进化翻面与 Boss 攻击

共鸣和进化复用遗物翻面结构，正面显示名称/状态，背面显示当前效果与配方。图鉴、构筑、核心选择和战斗侧栏均可查看；进化选择使用独立按钮。查看介绍不会消耗核心，战斗中查看会暂停模拟。

Boss 在 65%/30% 生命切换攻击序列，三章区域使用不同顺序。新增固定延时炸弹、预警轨道光束和带通道的弹幕墙，并轮换原有瞄准/螺旋攻击。炸弹预警至少 1.8 秒，光束预警 1.6 秒；范围与画面一致。目标位置在攻击创建时固定，角落会去除过近的重复目标。极寒区域布雷留一条空航道。攻击计时随模拟暂停，伤害遵守现有护盾、闪避与受击无敌，首领死亡清空危险队列。

危险队列独立于玩家视觉和遗物效果，最多 12 项，使用固定步长推进。新的攻击模式和数值仍需真人评估；自动化检查验证时序与范围，不代表已完成通关率验收。

## 0.5.0 压力、开场与美术

Boss 主技能之外新增双侧副炮，阶段一/二/三每 0.65/0.48/0.36 秒发射，分别每轮六/六/十枚弹丸。技能冷却也缩短，副炮在技能预警期间不会停火；预警时间、范围、受击无敌和死亡清理仍沿用 0.4.0。持续火力队列受上限和寿命控制。

第一章前三层只有普通战斗或事件，首层保证至少各一个；第四层开始恢复完整节点池。旧检查点中尚未访问的前三层经济服务替换为战斗/事件，ID、连线与已访问节点保留，不消耗抽样 RNG。

`ship-art.js` 为三种机体、六类敌舰与三种章节 Boss 提供独立原创矢量造型，机库与战斗共享绘制代码。`weapon-visuals.js` 绘制能量线、尾迹、导弹、枪口与命中效果。`assets/icons` 包含 109 张本地原创 SVG 设备插图，由 `scripts/generate-card-art.py` 生成；翻面交互保持独立确认按钮。新增效果不参与伤害判定，视觉队列仍独立于真实攻击，敌弹最后绘制。

`npm run report:pressure -- /path/to/previous/core.js` 输出固定、无敌玩家的 30 秒 Boss 压力对照。第一章阶段一平均在场弹幕从 12.8 增至 58.6，阶段三从 15.3 增至 131；这说明持续火力增加，不代表真人生存率或最终平衡验证。`npm run test:art` 输出模型、武器和图标图集及渲染抽样。一次 Chromium 抽样包含 148 枚敌弹，约 0.87ms/次绘制；该样本不是 Windows 实机帧率保证。

## 实现结构

- `data.js`：机体、武器、元素、遗物资格、配方与品质。
- `relic-catalog.js`：从提供的文档提取的 48 件遗物原始说明；调整项通过 data.js 的 RELIC_EFFECTS 显示当前版本数值。
- `core.js`：独立于画面的固定步长模拟，随机种子、星图、候选、伤害、状态与战斗。
- `render.js`：Canvas 星空、舰船、首领、光束与弹幕。
- `game.js`：页面、升级奖励队列、节点服务、存档与键鼠/手柄输入。
- `desktop/main.cjs`：桌面窗口，关闭 Node 集成、隔离上下文、保留沙箱。
- `tests/`：规则、稳定性与浏览器功能回归。

此版本主动偏离设计文档中射线 U01—U04 的 3/6 首领门槛，按玩家反馈统一为 1；仍保留原遗物配方。新进化选择把四种射线主形态视为互斥，旧存档已选的形态保留。舰载制造价格和战备补给属于新增原型规则，未进行真人全程经济平衡验收。


0.7.0 把手动射线/轨道炮统一为松开边沿释放，允许任意正蓄力并在满值钳制；自动与手动输入状态分别记录，自动关闭、暂停后的按键清理不当作释放。伤害按蓄力比例平方缩放，单次射线 Boss 预算与终结同步缩放；短充轨道炮的引力场、奇点、弹片和回响也不能获得完整伤害。`attackStrengths` 记录母攻击强度并限时清理，特效只读取质量不修改随机序列。

## 0.12.0 随机事件与配对代价（替代 0.11.0 的事件选择）

UNKNOWN_EVENTS 定义实验室/挑战/金币屋三种等概率结果。eventOutcome 以 seed+node.id 派生局部随机源，视觉滚动不使用战斗 RNG；进入事件揭晓一次，跳过动画只加速展示，不能选择另一种事件。prepareUnknownEvent 将结果与实验的三组遗物/代价缓存在节点上。读档回到进入前检查点后重新进入，也会重现相同事件与报价；历史 encounter 随地图存档保留。

实验室三张高品质卡各自绑定一项代价：第一张扣当前 hp 的 20–28（含两端均匀整数），第二张扣 maxShield 的 10–18，第三张扣 [111,222,333,444,555,666] 中一档。支付成功才直接发放该卡遗物并推进节点，没有先付代价再选另一组遗物。生命必须 hp>cost，护盾要求 maxShield>=cost（允许恰好 0），金币要求 coins>=cost。生命成本绕过护盾与减伤，不改 maxHp；护盾成本收缩当前 shield 到新上限。遗物本身的属性效果随后正常结算，例如恶魔契约仍有自身最大生命代价。翻面和取消禁忌确认不支付、不重抽；无法支付或候选已满可无奖励离开，事件只消费一次。

星图不生成 treasure 节点；该权重转为 event，前三层只有 combat/event。旧档所有 treasure 节点转换为 event，保留 id、links、path、资源和随机状态。金币只在随机抽中金币屋时通过 claimTreasure 领取一次，原章节/楼层奖励公式保留。

activeElementReactions 只按玩家实际已拥有的元素列出无序配对：0/1 元素无配对，2 元素 1 组，3 元素 3 组。构筑与战斗侧栏展示这些配方；翻面显示作用、层数条件、冷却及预算，战斗内查看时暂停，关闭后恢复，不改变游戏 RNG 或元素状态。全 15 组参考档案继续保留。

186 项规则检查包含三类成本边界、六档价格覆盖、直接发放及去重、翻面/重载不重抽、候选耗尽、错误事件拒绝交易、三类随机分布、地图移除与旧档迁移。test:contracts 在真实浏览器验证自动滚动和跳过、三张配对卡、死亡/负护盾禁用、精确付款、契约取消、读档、金币只领取一次、挑战跨安全事件计数、构筑的元素配对及战斗暂停/恢复。
